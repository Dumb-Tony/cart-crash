# Cart Crash M1 prototype

Open `index.html` directly in a desktop browser to play offline, or play https://dumb-tony.github.io/cart-crash/. This is the entire standalone game, with no dependencies or build step.

One hill, a pumpable dip, a safe rough lane and optional dumpster ramp. A/D steer, W/S lean, Space hold/release jump (dip release also boosts speed), Shift brake, Esc pause, R restart. Start-screen options include mute, reduced effects and local-record reset. Keyboard required; no touch/gamepad support.

Scope and human gates: `../../docs/PROTOTYPE_M1.md`. Tuning and developer replay tools: `../../docs/PARAMETERS_M1.md`. Actual evidence and limitations: `../../docs/PLAYTEST_LOG.md`. This is an M1 mechanic experiment, not a production scaffold or a passed enjoyment gate.
